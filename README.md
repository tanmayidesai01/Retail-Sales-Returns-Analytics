# Retail-Sales-Returns-Analytics
Retail Sales and Returns Analysis using MySQL and Power BI

## Project Overview
This project analyzes retail sales, profitability, customer purchasing behavior, and product returns using MySQL and Power BI.

## Tools Used
- MySQL
- SQL
- Power BI
- DAX
- Data Visualization

## Database Tables
- Customers
- Products
- Orders
- OrderItems
- DateTable

## Dashboards
1. Sales Performance
2. Product Analysis
3. Returns Analysis
4. RFM Customer Segmentation

## Key Metrics
- Net Sales
- Total Profit
- Profit Margin
- Total Orders
- Return Rate
- Customer Segments

## Business Objective
To identify sales trends, understand product return patterns, and segment customers to support data-driven business decisions.

## Files Included
- Power BI dashboard (`.pbix`)
- SQL scripts
- Dashboard screenshots

## Disclaimer
Refunds and profitability depend on the calculation assumptions used in the project. Results should be validated against the source data before making business decisions.
